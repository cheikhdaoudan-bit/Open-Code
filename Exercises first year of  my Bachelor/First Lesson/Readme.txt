# Python Exercises - First Year Bachelor (Swiss UMEF Dakar)

This repository contains my first Python programming exercises for my Bachelor's degree.

## Exercises Overview

### Exercise 1: Market (TTC Price Calculator)
*   **Description:** This program asks the user for a product's name and its price before tax. It then calculates and displays the final price including an 18% tax (TTC).

### Exercise 3: University Mean
*   **Description:** This program asks the user to enter 3 university marks using a loop. It then calculates and prints the mathematical mean (average) of these marks.

### Exercise 4: Class Loop (Sum)
*   **Description:** This program asks the user to input 5 marks. It calculates the total sum of all the marks combined.

### Exercise 5: Challenge (Count Passing Students)
*   **Description:** This program takes 5 student marks. It checks each mark and counts how many students got a mark greater than or equal to 10 ($>= 10$).
